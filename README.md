# Jteensy4000-pico2 synth

[WIP] This is experiment for porting **Jteensy4000** synth by **bk40-home** to Raspberry Pico 2 using **pico-audio** library (PJRC Teensy Audio library ported to Pico 2)

https://github.com/ghostintranslation/pico-audio

**What works:**

* usb midi
* multicore
* sound generation 
* output using i2s (pcm5102)
* preset switching

**What is not working:**

* gui code stripped
* fx section disabled
* code needs to be optimized
